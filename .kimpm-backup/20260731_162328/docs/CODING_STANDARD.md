# Coding Standard

## Readability
- 코드는 짧음보다 명확함을 우선한다.
- 변수와 함수 이름은 의도와 역할을 드러낸다.

## Function Design
- 하나의 함수는 하나의 핵심 책임만 가진다.
- 입력과 반환값을 명확히 한다.
- 지나치게 긴 함수는 책임별로 분리한다.

## Control Flow
- 중첩 조건을 줄이고 Early Return을 우선한다.
- 복잡한 조건은 의미 있는 이름으로 분리한다.

## Duplication
- 함께 변경될 가능성이 높은 반복 로직은 공통화한다.
- 단순 코드의 과도한 추상화는 피한다.

## Comments
- What보다 Why를 기록한다.
- 업무 규칙, 제약, 예외, 위험을 설명한다.
- 오래된 주석은 즉시 수정하거나 삭제한다.
